# Security Policy

## Supported Versions

We release patches for security vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not open a public issue for security vulnerabilities.**

If you discover a security vulnerability in Mosca Tee, please report it to us privately:

1. **Email**: security@moscatee.com (if available, or contact us through the website)
2. **GitHub Security Advisory**: Use the "Report a vulnerability" button on our GitHub repository

When reporting a vulnerability, please include:

- Description of the vulnerability
- Steps to reproduce (if possible)
- Potential impact
- Suggested fix (if you have one)

## What to Expect

- We will acknowledge receipt of your report within 48 hours
- We will work with you to understand and confirm the vulnerability
- We will keep you updated on our progress
- We will provide credit in our security advisories (if desired)

## Security Best Practices

When using Mosca Tee:

- **Update regularly**: Keep your Flatpak and browser up to date
- **Local processing**: Remember that all processing happens locally in your browser - your designs don't leave your computer
- **File permissions**: Be careful about file permissions when sharing designs
- **Dependencies**: Monitor the security of dependencies in your development environment

## Responsible Disclosure

We ask that you:

- Allow us reasonable time to fix the issue before public disclosure
- Avoid testing vulnerabilities on production systems
- Not access or destroy other users' data
- Follow applicable laws and regulations

Thank you for helping keep Mosca Tee secure!
