# Release draft - Mosca Tee

Version: 0.0.1

## Summary
Initial desktop-ready release of Mosca Tee adapted to Electron and prepared for Flathub distribution. Includes Flatpak manifest and application metadata.

## Changelog
- Initial packaging for Electron and Flatpak
- Added Flatpak manifest and metainfo
- README updated with project description
- Added public icon for packaging

## Assets
- Binary (Electron build) will be generated by CI or via local `electron-builder` run.
- Flatpak manifest: `flatpak/com.moscatee.Editor.yml`
- Metainfo: `flatpak/com.moscatee.Editor.metainfo.xml`

## Publishing steps
1. Tag the release: `git tag -a v0.0.1 -m "Initial release"`
2. Push tag: `git push origin v0.0.1`
3. Create release on GitHub (Title: v0.0.1) and upload any build artifacts if available.
4. Open PR to Flathub following their submission guidelines. Attach the Flatpak manifest or point to the repository.

## Notes
- Ensure the `commit` field in `flatpak/com.moscatee.Editor.yml` matches the commit you want Flathub to build from.
- For local Flatpak testing, install `flatpak-builder` and follow `ELECTRON_FLATPAK_SETUP.md`.
